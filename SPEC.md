# SHABU 888 Feature Specification
## Goal
Public bilingual Thai/English shabu & BBQ web app.
## Requirements
Home hero; bilingual menu cards and search/filter; Standard 299, Premium 399, Ultimate 499 sample packages; reservation date/time/guests/zone/package/name/phone; shared Available/Fully Booked status in production; SHABU-xxxxx reservation ID; promotions/rewards; member flow; QR ordering; contact/map/social; responsive UI.
## Constraints
20 tables, 4–6 seats each; Indoor/Outdoor/Private; open 08:00–20:00 daily; 30-minute booking slots; 120-minute dining; GitHub Pages front end; Firebase backend.
