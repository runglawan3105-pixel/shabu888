# SHABU 888
Bilingual Thai/English restaurant web app for ร้านชาบู888.

## Features
Home, bilingual menu/search/filter, buffet packages, reservation UI, promotions, QR Ordering demo, contact, responsive design and Firebase integration template.

## Business rules
- Open daily 08:00–20:00
- 20 tables, 4–6 seats/table
- Indoor / Outdoor / Private
- Reservation every 30 minutes
- Dining duration 120 minutes

## Production status
The GitHub Pages build is a front-end prototype. Reservations use browser localStorage until Firebase is configured. Real shared availability, membership and kitchen orders require Firebase Auth/Firestore plus trusted transactional backend logic to prevent double booking.
